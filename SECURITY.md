# Политика безопасности

Не раскрывайте уязвимости и чувствительные сведения о среде в публичных issues.

Сообщайте об уязвимости приватно через GitHub Security Advisories этого репозитория. Укажите затронутую версию, шаги
воспроизведения, влияние и, если возможно, вариант исправления. Не прикладывайте реальные credentials, промпты,
ответы, корпоративные данные или приватные endpoints.

Поддерживаются последний опубликованный release и текущая основная ветка. Исправления безопасности работают по
принципу fail-closed и могут отключить возможность до подтверждения её безопасности.

PromptForge сам по себе не делает среду безопасной. Операторы отвечают за защиту хоста, сетевые политики, жизненный
цикл credentials, проверку внешних endpoints и независимое ревью.
