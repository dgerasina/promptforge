# Участие в разработке

Мы принимаем сфокусированные pull requests.

1. Создайте issue с описанием проблемы и ожидаемого поведения.
2. До реализации добавьте или обновите тесты.
3. Сохраняйте core нейтральным к конкретным поставщикам, а проектную логику размещайте в project pack.
4. Запустите описанные в README проверки схем, тестов, безопасности, переносимости и документации.
5. Убедитесь, что в изменениях нет runtime-состояния, credentials, приватных путей, промптов, ответов, diff или
   корпоративных данных.
6. Используйте conventional commit, например `feat: add portable task adapter`.

Все изменения передаются на условиях Apache License 2.0.
